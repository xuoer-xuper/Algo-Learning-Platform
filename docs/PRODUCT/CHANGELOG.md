# 更新日志

本文件记录面向用户和维护者的可见变化。

## 未发布

### 新增

- 暗色模式：设置 → 外观新增主题选项，可选跟随系统（默认）、浅色、深色。切换即时生效，重启后保持，桌宠与拆分出去的窗口一并跟随。
- 桌宠置顶方式可选：跟随窗口（默认）、全局置顶、停靠不置顶，设置内即时生效并在重启后保持。
- 笔记编辑器支持数学公式（行内与块级 LaTeX），复用已随编辑器打包的 KaTeX 字体。

### 变更

- 设置页改为左侧分区导航（外观、Coach 桌宠、地址栏搜索、AI 模型、站点管理、账户与同步、数据与备份、学习概览、运行诊断），不再把九块设置堆在一页里靠滚动找。窄窗下导航自动横置为可滚动条带。
- 题库侧栏、首页、学习统计在数据读取期间显示占位骨架，读完再显示内容，不再先闪一下空白或旧值。
- 全应用的等待与空白提示统一：题目详情、时间轴复盘、Coach 指标、笔记列表与编辑器、脚本管理、地址栏建议、平台登录态、内部页切换在读取期间一律显示占位骨架，"确实没有内容"则是带图标与一句说明的空状态提示，两者不再长得一样。
- 全应用动效统一：内部页切换有淡入淡出过渡，标签新建/关闭/激活有对应动画，对话框与下拉菜单有双向出入场动画，所有按钮与可点击行有悬停反馈。键盘导航会显示焦点环，鼠标点击不会（输入框除外）。
- 读屏软件现在会把等待中的区域读成一句"加载中"，而不是念出一串空白节点。
- 题库侧栏折叠/展开有了宽度过渡动画。

### 修复

- 修复学习统计刚打开时把"总题数"等四张卡显示为 `0`、四个列表显示"暂无数据"的问题：那是数据还没读到，不是真的没有记录。
- 修复题库侧栏加载期间显示"暂无记录"的问题，同样是把"还没读到"说成了"你没有"。
- 题库侧栏筛选后没有结果时，提示改为"没有符合筛选条件的题目"，不再与"暂无记录"混为一谈。
- 修复地址栏建议在查询期间显示"暂无本地建议"的问题：那时候还在查，不是查完了没有。
- 修复设置页平台登录态、Coach 桌宠配置在读取期间显示为空的问题。
- 题库侧栏、首页与学习统计的列表行现在可以用键盘 Tab 聚焦、回车或空格打开，此前这些行只能用鼠标点。
- 修复桌宠盖住应用内对话框与菜单的问题：默认模式下不再全局置顶，弹出原生菜单或文件对话框时自动退到后面。
- 修复桌宠持续闪烁、无法点击与拖动、主窗口任务栏按钮反复闪烁的问题。默认（跟随窗口）模式下，桌宠让位给原生菜单的判定此前直接采信每一次窗口失焦，而让位本身会再次扰动焦点，两者首尾相接使桌宠在两个层级间来回跳；现在改为失焦后短暂复核再让位，一闪而过的焦点抖动不再触发。让位时机对用户没有可感知的变化。
- 修复桌宠气泡与聊天面板重复控制点击穿透导致的闪烁问题。此前 CoachPet、CoachBubble、CoachChatPanel 三个组件都监听鼠标事件并切换窗口命中测试状态，多层嵌套时形成反馈循环：命中测试变化触发新的鼠标事件、鼠标事件又切换命中测试，无限循环使桌宠闪烁、任务栏状态条不断切换。现在只在最外层 CoachPet 控制穿透，子组件不再重复监听。
- 修复桌宠气泡位置不跟随缩放的问题：此前气泡偏移写死为默认缩放下的数值，放大后压在桌宠身上、缩小后悬空。

## 1.0.0 - 2026-07-04

### 新增

- 完成 v1.0 桌面应用规划，覆盖七站刷题、题目识别、提交记录、统计分析、笔记、站点扩展、备份导入导出和 Windows 打包。
- 增加本地 SQLite 备份、学习数据 JSON 导入导出、冲突预览和同步兼容文档。
- 增加 Cookie 元数据本地保存和安全摘要查询能力，renderer 只能查看授权状态摘要，不暴露 Cookie 值。
- 增加 `npm run test:all` 全量自动验证入口，覆盖 typecheck、lint、架构/安全/文档/打包守卫、IPC contract、AI、adapter、submissions、DB、Electron smoke 和 UI screenshot。
- 增加 `npm run test:ai`，验证本地 AI 建议、薄弱标签和复习计划可追溯到本地数据，且不泄漏敏感 payload。
- 增加 Windows NSIS x64 打包脚本、应用图标和 electron-builder 白名单配置。
- 增加发布流程、故障排查、数据库迁移回滚、同步兼容和安卓只读数据接口文档。

### 变更

- 提交监测 adapter 按站点目录整理，registry 只负责注册和查找。
- Renderer 业务组件拆分为 feature 内部组件、hook 和 API helper，减少顶层文件职责。
- renderer 截图验收改为真实组件和 CSS bundle，并检查关键容器越界、敏感文本和统计图表绘制。
- Windows 打包产物解包 `better-sqlite3` 原生模块，避免安装包运行时加载 SQLite 驱动失败。
- 项目文档从协作开发任务状态收口为 v1.0 成品文档，保留架构、接口、数据、版本、功能和运维资料。

### 修复

- 修复 Codeforces、Nowcoder、VJudge 等站点提交监测提前入库、误抓自测、公开状态行误判和信息缺失问题。
- 修复截图验收中主内容区、统计页 modal 和平台分布图表的布局/绘制问题。

## 0.6.0 - 2026-07-03

### 新增

- 新增本地 Markdown 笔记系统，支持题目关联笔记、所见即所得编辑和图片附件保存。
- 新增 AI 上下文导出、复习建议、薄弱标签分析、阶段总结、复习计划和 AI 输出本地保存能力。
- 新增 Codeforces Rating 同步与统计大盘中的学习建议展示。

### 变更

- 明确 AI 模块只能读取核心学习数据并写入独立产物区，不能修改题目、提交、访问和统计核心数据。
- 代码片段管理方案已撤销，AI 上下文导出直接读取原始提交记录。

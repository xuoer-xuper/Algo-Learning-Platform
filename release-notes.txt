## v2.0.0-beta.2

### Bug Fixes
- 修复打包后桌宠窗口加载错误页面的问题
- 修复浮窗背景截图 DPI 缩放导致的"截取部分放大"问题
- 修复桌宠拖拽、粒子环偏移和气泡按钮换行问题
- 修复点击桌宠立即显示加载气泡并防止并发请求

### Features
- 新增 AI Coach 桌宠、本地规则引擎、分级提示和比赛模式硬保障
- 新增过程复盘、干预效果指标和审计记录
- 新增可选 LLM 智能提示与自由聊天
- 聊天面板接入 Markdown 渲染（react-markdown + remark-gfm），LLM 回复支持代码块、表格、列表等
- white-space: pre-wrap 仅作用于用户消息，assistant 消息由 Markdown 处理换行
